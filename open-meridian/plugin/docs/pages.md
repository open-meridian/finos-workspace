# Pages

- **Workspace**, under Open and View: Workspace's dashboards. The starter
  dashboard, "FX reference rates", is on its Apps page.
- **Datasets**, under Manage: each dataset the plugin reads, and whether it
  is entitled to it.

Each read the Workspace page shows is also a read tool on the deployment's
MCP surface, under Open and View as the page is: `read_fx_rates` (the rates
table and chart), `read_dataset_ages` (the dataset ages) and
`read_instrument` (the instrument lookup). Each answers what its widget
shows, and is refused as its widget is.

Workspace's own UI works at widths from 375 px with no sideways scroll.
