# Troubleshooting

- **"Refused: This plugin is not entitled to …"**: a deployment admin
  entitles it on Data sources.
- **"The lake holds no reference rate yet."**: the data plugin has recorded
  none yet, or the master holds no cash instrument for the euro.
- **The page says to open it from the dashboard**: it is reached through the
  plugin's area on the dashboard, under Open or View.
